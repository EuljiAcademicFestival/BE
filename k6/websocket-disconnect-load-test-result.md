## 22. 종료 경합 수정 후 200명 최종 검증

기록일: <date start="2026-11-16" />

### 조건과 판정

사용자가 재시작한 실제 8080 서버에서 00:54:37~00:58:51 KST에 실행했다. 200명 첫 관측은 00:55:49 KST이며, 계정 준비 후 각 180초간 MOVE 약 10Hz와 좋아요 REST 약 초당 1회를 수행했다. 기존 k6/websocket.js와 회원 203명의 개발 DB 3306을 사용했고 재시드하지 않았다. 사전 단일 소켓 연결·정밀도 검사는 본 부하 기준값에서 제외했다.

이번 목적은 21번의 종료 경합 수정 검증이다. 동일한 로컬 환경의 1회 실행이며 병목 전체 해결이나 장시간 운영 검증으로 확대하지 않는다.

모든 k6 thresholds 통과, 종료 코드 0. 32건과 30건은 서로 다른 실행에서 발생한 메시지 수로 일대일 대응하는 동일 메시지가 아니다. 수정 후에도 종료된 연결의 늦은 메시지가 발생하지만, 성공이나 인증 오류로 세지 않고 ignored로 구분한 것을 확인했다.

### 종료 시점 확인

- 00:58:47.856 KST: 연결·캐릭터 200, 거부 0, ignored 0.
- 00:58:48.871 KST: 연결·캐릭터 3, 거부 0, ignored 30.
- 00:58:49.114 KST: 연결·캐릭터 0, 거부 0, ignored 30.
- 종료 후 1초 간격으로 두 번 더 확인한 00:58:51.151까지 0명·거부 0·ignored 30이 유지됐다.

k6 송신 360,057개 = AUTH 200 + 수락 MOVE 359,827 + 종료 후 ignored 30으로 정확히 일치한다. 정상 이용 중 ignored는 표본에서 관측되지 않았으며, 종료 구간에서 증가했다. 기존의 오류 수치를 삭제한 것이 아니라 별도 지표로 남겼다.

### 정상 기능·자원 확인

- 총 HTTP 36,254건 중 준비 가입·로그인 400건, 본 좋아요 35,854건. 준비의 예상 가입 중복 409 200건 외 HTTP 4xx·5xx는 0건.
- 위치 프레임 314,358개, 좋아요·순위 프레임 79,925개. 전원 위치·공통 상태를 수신했고 공통 상태 응답 계약 실패 0건.
- 이동 반영 평균 60.61ms·최대 148ms, 좋아요 수 반영 평균 110.91ms·최대 241ms.
- 총수신 5,344,149,753바이트, 약 5.344GB. HTTP·WebSocket 합계이며 이 실행에서 위치 정밀도·전송 주기는 바꾸지 않았다.
- Hikari 획득 36,855회 = 준비 REST 400 + 좋아요 35,854 + 입장 프로필 200 + 공통 상태 SELECT 401. 차이 0회.
- 공통 상태 SELECT 실패·연결 획득 타임아웃 증가 0건.
- 약 1초 표본 pending 최대 2, active 최대 10. 00:58:37.704 KST에 200명 접속 중 pending 2가 한 표본에서 관측됐다. 약 5초 Prometheus 표본 pending 최대는 0이었다. 관측 간격이 다르므로 서로 모순되지 않으며 DB 대기가 완전히 없다고 기록하지 않는다.
- Prometheus 평균 연결 획득 대기 약 0.007ms, 획득 시간 max 8ms.
- 앱 CPU gauge 표본 최대 약 22.55%, 사용 힙 최대 약 202.15MiB. 로컬 공유 환경의 표본이며 변경의 순수 CPU 효과는 분리하지 않았다.
- 실행 전후 DB 읽기 검사에서 좋아요 집계 불일치 모두 0건. 사용자 8080 서버는 종료하지 않았다.

### 결론과 한계

이번 200명 동시 이용·종료 실행에서 늦은 메시지의 오류 오분류는 재발하지 않았고, 의도한 ignored 분류와 연결·공간 정리를 확인했다. 기존 인증·좌표·빈도 제한 오류에 대한 회귀 테스트 30개·빌드 통과는 21번의 구현 단계 기록이다.

프론트엔드의 화면 부드러움, 실제 AWS 운영, 장시간·불안정 네트워크·모든 강제 종료 조합을 검증한 것은 아니다. pending 2 표본도 남아 있어 이번 종료 검증을 DB 병목 전체 해결로 해석하지 않는다. 프론트엔드 메시지 계약 변경이 없어 WebSocket 명세에는 측정 결과를 추가하지 않는다.
